# QuantumGlitch Studio

Source of the studio site, https://quantumglitch-dev.github.io/ (GitHub Pages, served as is from `main`).

- `/` — studio page
- `/herding-cats/privacy/` — privacy policy of Herding Cats

`assets/img/studio/` holds the studio mark (wide logo, light and dark), favicons, the web manifest and the link preview, copied from the studio brand kit (`brand/` in the game repository, built by `tools/brand/make_brand_kit.py`). The logo SVGs have their text as outlines, so the page needs no extra font.

The Fredoka font is under the SIL Open Font License 1.1 (`assets/fonts/OFL.txt`).
